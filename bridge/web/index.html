Плагины

Плагин — программа на машине моста: она решает, что показать, а мост рисует это для рамки. Добавить плагин можно только на самой машине (см. bridge/plugins/README.md); здесь их можно настроить, посмотреть и показать.

Задания

Задание запускает плагин по расписанию и отправляет результат рамкам. Неспящей рамке картинка приходит сразу; спящая (на батарее, с bridge.url) забирает её при следующем пробуждении. Одинаковая картинка второй раз не отправляется.
