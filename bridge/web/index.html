Frames

OpenDisplay server

Home Assistant and other OpenDisplay clients connect to the bridge. The frame must be awake; the bridge refuses an image while it is asleep.

Add a frame by address

For networks where discovery (mDNS) does not reach, and for frames with a portal password.

Plugins

A plugin is a program on the bridge's own machine: it decides what to show, and the bridge draws it for the frame. A plugin can only be added on that machine (see bridge/plugins/README.md); here you can configure one, preview it and show it.

Jobs

A job runs a plugin on a schedule and sends the result to the frames. An awake frame receives the picture at once; a sleeping one (on battery, with bridge.url) picks it up on its next wake-up. The same picture is not sent twice.
