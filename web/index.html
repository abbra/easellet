Device protection

For now the page is open to everyone on the home network. A password turns on HTTP Basic — that is a lock on the door, not encryption: traffic still goes over plain HTTP. A new password applies after web stop and web start from the console.

Firmware

A new image is written to the slot the frame is not running from, and the frame restarts into it. A build that does not start is replaced by the one running now on the next reset — a failed update costs a minute, not the frame.

The image is target/xtensa-esp32s3-espidf/release/easellet.bin from a release build. The first OTA needs a serial flash of the bootloader, the partition table and the app: see “Flashing” in README.md.

The gallery shows what is drawn on the screen; only what lies in EASELTEST can be deleted — the rest of the card belongs to the firmware.
