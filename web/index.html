Защита устройства

Пока страница открыта всем в домашней сети. Пароль включает вход по HTTP Basic — это замок на дверь, а не шифрование: трафик идёт по обычному HTTP. Новый пароль начнёт действовать после web stop и web start с консоли.

Галерея показывает то же, что нарисовано на экране; удалять можно только то, что лежит в PFTEST — остальное на карте принадлежит прошивке.
