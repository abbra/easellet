# Changelog

Versions are `MAJOR.MINOR.PATCH` and tags are `vX.Y.Z`. `Cargo.toml` holds the
number and `tools/check-version.py` proves that every other copy agrees with it.
From `0.2.0` on, a section is generated by `git cliff` from the conventional
commits (`scripts/release.sh`). `0.1.0` was written by hand: a first stage is a
summary, and fifty commit subjects in a row do not tell the same story.

## [0.1.0] - 2026-11-03

The first stage. A Waveshare ESP32-S3-PhotoPainter that boots, reports what its
hardware does, shows pictures from a card, is driven from a browser, and listens
when a question is addressed to it.

### Added

- **firmware:** a console and diagnostics for the parts the board actually has —
  GPIO, the SHTC3 sensor, the AXP2101 PMIC, the PCF85063 clock, SD mount, audio
  loopback — with the panel refresh at about 30 s for an 800x480 six-colour
  image and the vendor's full 180-degree rotation.
- **firmware:** a card slideshow, a picture upload portal, and firmware updates
  over OTA into the second app slot, with rollback to the running slot.
- **firmware:** a voice loop: wake word, voice-activity detection, µ-law upload
  to a LAN bridge, and playback of the answer.
- **bridge:** speech recognition, language models and speech synthesis behind one
  small HTTP service, so the device needs no model and no key.
- **bridge:** a plugin system with twelve shipped plugins (`weather`, `news`,
  `ci`, `note`, `photo-folder`, `ai-image`, `hello`, `system`, `agenda`, `sun`,
  `air`, `spot`), each a program that prints JSON, plus a scheduler with
  per-frame jobs and a card renderer for the panel's six colours.
- **bridge:** several plugin outputs composed into one panel — five fixed
  presets, arranged per frame in the web interface — so a frame refreshes once per
  screen change instead of once per job.
- **bridge:** frame discovery over mDNS and OpenDisplay, and a web interface in
  English and Russian for frames, plugins, jobs and settings.
